## Project Overview
**Khula-Nathi** is a web platform designed to empower local community initiatives, sustainable development projects, and food donation programs. Built with a custom, lightweight design system, the platform provides an intuitive and accessible interface for community members, volunteers, and donors to explore programs, view project galleries, and get involved.
--## Purpose and Features
### Purpose:
Khula-Nathi is a dedicated web platform designed to support local community development, sustainable agriculture, and youth empowerment initiatives across South Africa. The primary objective of the site is to connect community members, volunteers and donors with local outreach programs while raising awareness for key social causes. Built around an accessible, nature-inspired visual identity, the platform communicates the organization's mission through clear messaging and engaging visual showcases. 
### Key Features:
-	Feature 1: Multi-Page Site Navigation: Features a sticky navigation bar with active link states that allows users to move smoothly between the homepage, about section, gallery, contact page, and get-involved portal.
-	Feature 2: Interactive Program & Gallery Showcases: Displays community initiatives, agricultural projects, and event photo galleries using responsive card grids and styled circular frames with hover animation effects.
-	Feature 3: Mobile-First Responsive Layouts: Built with fluid CSS Grid and Flexbox systems to ensure seamless readability and consistent visual structure across mobile phones, tablets, and desktop displays.
-	Feature 4: Custom Color & Branding Design System: Utilizes CSS custom variables (CSS variables) for consistent forest-green, earth-tone, and warm neutral branding across all web pages.

These features work together to create an accessible, engaging, and trustworthy online presence for Khula-Nathi. The multi-page navigation and responsive mobile layouts ensure that visitors can effortlessly browse programs, read project details, and view media galleries on any device without encountering broken layouts or confusing menus. Visual elements like interactive image cards and smooth hover animations bring the community projects to life, making the platform feel modern and active while keeping users engaged. Furthermore, the unified custom branding establishes visual credibility, and the integrated contact forms turn visitor interest into action by making it fast and straightforward for donors, volunteers, and partners to connect with the organization. 
## Design Considerations The design of the **Khula-Nathi Solutions** was based on the following key considerations:
1.	**User Experience (UX)**: The website was designed with the goal of providing an intuitive and easy-to-navigate user interface, ensuring a seamless user experience.
   
2.	**Responsiveness**: The website was built to ensure it performs well on different screen sizes, with particular attention to device compatibility.
3.	**Simplicity**: The design is minimalistic, focusing on core features without overwhelming the user.    
4.	**Performance**: Code optimization was considered to ensure fast response times and low battery usage. ---

## Challenges and Learnings During the development of this project, I encountered several challenges, including:


1.	**Challenge 1**: Managing nested folder structures caused broken image links and unstyled HTML pages when files were accidentally placed inside asset directories instead of the root folder.

-	**Solution**: Reorganized the project root by moving all main HTML files to the top level, renaming the primary landing page to index.html, and updating image and style links using relative file paths.

2.	**Challenge 2**: Adapting multi-column grids, flexbox galleries, and circular image frames to display consistently across mobile, tablet, and desktop screens presented layout breaks on smaller viewports.
	**Solution**:Implemented CSS media queries alongside dynamic CSS Grid (repeat(auto-fit, minmax and Flexbox properties to ensure elements scale and wrap naturally across all screen sizes.
-	From these challenges, I learned important lessons in debugging, using version control, and automating build processes with GitHub Actions. ---
